Personal portfolio built with plain HTML, CSS and JavaScript, no dependencies.

Live at [portfolio.bautiavila.com](https://portfolio.bautiavila.com)

## Features

- Bilingual Spanish/English with `?lang=`, saved preference and browser detection
- Project galleries with lightbox and expandable descriptions
- Self-hosted Inter font
- Accessible focus states and reduced-motion support
